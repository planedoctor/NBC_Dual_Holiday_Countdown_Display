1. Power Up Your Display

Connect the USB power cable to the display and plug it into a USB power adapter.

The display will briefly flash when power is connected, then remains blank while it connects to Wi-Fi and obtains the current time.

Once the display has successfully connected to Wi-Fi and synchronized its time, the countdown will appear.

2. Connect the Display to Your Wi-Fi

  1. On your phone, tablet, or computer, connect to the Wi-Fi network named DualHoliday-Setup using password countdown123.
  2. Your device may show “No Internet Connection.” This is normal.
  3. The Dual Holiday Countdown Setup page should open automatically. If it does not, open a web browser and go to 192.168.4.1.
  4. Select Configure Wi-Fi.
  5. Select your home's 2.4 GHz Wi-Fi network from the list.
  6. Enter your Wi-Fi password and select Save.
  7. The display will connect to your Wi-Fi and synchronize its time.
  8. Once connected, the countdown will appear on the display.

3. Open the Display's Control Page

Once the display is connected to your Wi-Fi, you can access its control page from any device connected to the same Wi-Fi network.

Open a web browser and enter:

Open dualholiday.local

The Dual Holiday Countdown control page will open. From this page, you can view the display's status and change its settings.

4. Select Which Displays Are On

From the Dual Holiday Countdown control page, find Displays On and choose which countdown display(s) you want illuminated:

Halloween — Halloween countdown only

Christmas — Christmas countdown only

Both — Both countdowns

Select your preferred option.

5. Set Your Time Zone

  1. On the control page, find Time Zone.
  2. Select your local time zone from the list.
  3. Select Save Settings.

The display will use this time zone for its clock and countdown calculations.

6. Firmware Updates

The latest firmware and project information are available on the HomeHackery GitHub project page.

If you experience a problem with the display, check the GitHub page for the latest information and available updates. Help is also available through the project information there.

Firmware update instructions are provided separately with each update.

View Firmware Releases

7. Moving the Display or Changing Wi-Fi Networks

If you move the display to a different location or change your home Wi-Fi network, the display will automatically enter Wi-Fi Setup Mode if it cannot connect to the saved network.

Simply repeat Step 2: Connect the Display to Your Wi-Fi and select your new Wi-Fi network.

Once the new Wi-Fi information has been saved, the display will automatically connect and resume normal operation.

Important: If Wi-Fi temporarily goes offline while the display is already running, the countdown will continue. If the display loses power while Wi-Fi is unavailable, the countdown will remain blank until Wi-Fi is restored and the display can synchronize its time.
